# Минимальный интерфейс клиента для PCM03

Спецификация экранов для собственного приложения: что показывать, откуда
брать значение, что происходит при нажатии. Коды команд — в
[`happygo-ble-protocol.md`](happygo-ble-protocol.md).

Обозначения: `0x00[3]` — байт 3 нагрузки ответа на команду `0x00`.

---

## 0. Поправки к наблюдениям

Четыре места, где увиденное в приложении расходится с тем, что на самом деле
происходит.

**Time Preset — это не таймер после старта, а будильник.** Вы задаёте
**время суток** (час и минута) и режим; в это время машина сама запустит
заваривание. `Ding dong` / `Di di` / `Bu gu` / `Bi bi` — мелодия напоминания,
плюс переключатель «тихо / со звуком». Косвенное доказательство: если выбрать
время, совпадающее с текущим до минуты, приложение предупреждает, что задача
выполнится завтра. Таймера «пикнуть через N минут после старта экстракции» в
протоколе нет вообще.

**Уровней заряда пять, а не четыре** — иконки `dianliang_tubiao0…4`. Но это
только для картинки: в `0x00[1] & 0x7F` приходит **точный процент**, и своё
приложение может показывать его цифрой.

**Скорость экстракции — не три градации.** Это ползунок по диапазону, который
устройство сообщает в `0x17` (байты 10 и 11 — min и max). `Low` / `Medium` /
`High` — просто подпись под текущим значением: приложение делит диапазон на
трети и подписывает, в какую из них попало. Ваши ~10 делений — это и есть
`max - min + 1` вашей машины. Диапазон `0..2` подставляется только как
аварийный, если устройство прислало `max < min`.

**История — только посуточные счётчики.** Более точных записей нет: `0x06`
отдаёт массив «чашек за день» начиная с сегодняшнего дня назад, `0x19` —
счётчик за сегодня. Времени приготовления каждой чашки устройство не хранит.
Всё, что в приложении выглядит как разбивка по неделям и месяцам, оно считает
само из этих суточных чисел в своей локальной базе.

**Про «выключенную машину в коробке»**: она не выключена, а в дежурном режиме
(`0x00[4] == 0` → `standby`, в приложении «Standby»). BLE-радио продолжает
рекламироваться, микроконтроллер жив, нагрев выключен. Отсюда следствие,
которое стоит учитывать в своём UI: заваривание можно запустить командой
`0x02` из сумки — подтверждение перед стартом здесь не формальность.

## 1. Экран «Устройства»

Нужен только чтобы найти и подключиться.

| Элемент | Источник |
|---|---|
| список найденных | скан BLE, имя начинается с `BL_PCM03` |
| имя в списке | своё, из локального хранилища; иначе имя из рекламы |
| идентификатор | MAC из `manufacturerData` рекламы |
| статус | Disconnected / Connecting / Connected |

Кнопки: **Поиск**, **Подключить**, **Отключить**, **Удалить**.
Переименование — чисто локальное, устройству ничего не отправляется.

После connect выполнить последовательность из §9.2 протокола и перейти на
главный экран.

---

## 2. Главный экран

Единственный обязательный экран. Всё, что на нём, приезжает в push-нотификации
`0x00`, кроме уставки и границ температуры.

### Что показывать

| Элемент | Источник | Примечание |
|---|---|---|
| имя машины | локальное хранилище | — |
| модель | строка 3 из `0x08` | `PCM03` / `PCM03S` / `PCM03SMAX` / `PCM03SPRO` |
| заряд, % | `0x00[1] & 0x7F` | точное значение |
| идёт зарядка | `0x00[2] & 0x80` | |
| заряжено | `0x00[2] & 0x40` | показывать вместо «идёт зарядка» |
| текущая температура | `0x00[3]`, °C | ваши «32 градуса» |
| уставка температуры | ответ `0x15[2]`, °C | обновляется и в эхе `0x16[0]` |
| границы уставки | `0x15[0]` / `0x15[1]` | ограничить регулятор |
| режим / состояние | `0x00[4]` | 7 значений, см. ниже |
| ошибка | `0x00[5]` | 0 = нет |
| связь | состояние GATT | |

Состояния `0x00[4]`:

| Код | Показывать |
|---|---|
| 0 | Ожидание |
| 1 | Нагрев и экстракция |
| 2 | Нагрев и экстракция — готово |
| 3 | Экстракция |
| 4 | Экстракция — готово |
| 5 | Нагрев воды |
| 6 | Нагрев воды — готово |

Коды ошибок `0x00[5]` — их обязательно выводить, это единственный способ
понять, почему машина не работает:

| Код | Смысл |
|---|---|
| 0 | норма |
| 1 | сухой ход (нет воды) |
| 2 | перегрев батареи — подождать |
| 3 | КЗ нагревателя — в сервис |
| 4 | низкий заряд при нагреве |
| 5 | низкий заряд |

### Управление

* **Регулятор уставки** — при отпускании шлёт `0x16 [температура]`.
  Оригинал спрашивает подтверждение («Изменить уставку?»); можно не спрашивать.
* **°C / °F** — переключатель прямо на этом экране. Чисто визуальный:
  протокол всегда в Цельсиях, `F = round(C × 1.8 + 32)`.
* **Старт** — меню из трёх режимов, затем `0x02 [1, WorkMode]`:

  | Пункт | `WorkMode` | Что делает |
  |---|---|---|
  | Нагрев и экстракция | **1** | греет воду и проливает |
  | Только нагрев | **0** | греет воду без пролива |
  | Только экстракция | **2** | проливает без нагрева |

  Осторожно: в командах таймера те же режимы пронумерованы иначе (см. §3).
* **Стоп** — `0x02 [0, 0]`.

### Блокировки

Устройство «занято», когда состояние **не** из `{0, 2, 4, 6}`.
Пока занято: показывать Стоп вместо Старта, запретить менять уставку и
параметры заваривания. Оригинал в этом случае говорит «устройство работает,
попробуйте позже».

При заряде ниже порога и запуске режима с нагревом (`WorkMode` 0 или 1) —
предупредить: «батареи может не хватить на полный нагрев, экстракция горячей
водой останется доступна».

Перерисовывать экран не чаще раза в 800 мс — нотификации приходят чаще.

## 3. Экран «Параметры заваривания»

Четыре регулятора. Границы каждого приходят в ответе `0x17`, текущие значения —
там же.

| Регулятор | Значение | Min | Max | Шаг |
|---|---|---|---|---|
| Скорость экстракции | `0x17[0]` | `0x17[10]` | `0x17[11]` | 1 |
| Предсмачивание, с | `0x17[1]` | `0x17[2]` | `0x17[3]` | 1 |
| Standstill, с | `0x17[4]` | `0x17[5]` | `0x17[6]` | 1 |
| Время экстракции, с | `0x17[7]` | `0x17[8]` | `0x17[9]` | **10** |

Байты 10–11 есть не всегда: если нагрузка короче 12 байт, диапазон скорости
неизвестен — подставляйте `0..2`.

Под скоростью можно подписывать Low / Medium / High по трети диапазона:

```
span = max - min
value <  min + span/3        -> Low
value <  min + 2*span/3      -> Medium
иначе                        -> High
```

**Сохранить** → `0x18 [скорость, предсмачивание, standstill, экстракция]`.
Если устройство не прислало параметры времени экстракции (нагрузка `0x17`
короче), отправлять три байта без последнего.

**Сбросить к заводским** → `0x20`. Ответ приходит пятью байтами
`[скорость, предсмачивание, standstill, уставка_температуры, экстракция]` —
обновить по ним и экран, и уставку.

Уставку температуры оригинал дублирует и здесь; можно оставить её только на
главном.

---

## 4. Экран «Отложенный запуск» (опционально)

Открытие → `0x24`, ответ 6 байт заполняет форму.

| Поле | Байт | Значения |
|---|---|---|
| Режим | 0 | **0** нагрев+экстракция, **1** только нагрев, **2** только экстракция |
| Час | 1 | 0–23 |
| Минута | 2 | 0–59 |
| Напоминание | 3 | 0 тихо, 1 со звуком |
| Мелодия | 4 | 0 Ding dong, 1 Di di, 2 Bu gu, 3 Bi bi |
| Включён | 5 | 1 / 0 |

Обратите внимание на нумерацию режима: она **не совпадает** с `WorkMode` на
главном экране. Здесь `0` — нагрев с экстракцией, на главном `0` — только
нагрев.

**Сохранить / Старт** → `0x23` с теми же шестью байтами и последним `1`.
**Стоп** → те же байты с последним `0`.

Если выбранное время совпадает с текущим до минуты, предупредить, что задача
сработает завтра — устройству при этом уходят те же час и минута.

---

## 5. Экран «Статистика» (опционально)

* открытие → `0x19` (чашек сегодня) и `0x06 [0]` (история);
* ответ `0x06` собирается из фрагментов; `payload[2]` — сегодня,
  `payload[3]` — вчера и так далее; `payload[0]` и `payload[1]` приложение не
  использует;
* всё, что сложнее «чашек за день», считайте у себя, накапливая в своей базе;
* **Очистить** → `0x06 [1]`, с предупреждением, что данные не восстановить.

---

## 6. Что можно не делать

Из оригинального приложения смело выбрасывается: аккаунт и вход, обратная связь
и почта, описание продукта, юридические экраны, экспорт истории в Excel, выбор
языка, обновление прошивки по воздуху. Ничего из этого не нужно для управления
машиной.

Экран «Информация об устройстве» (модель и две строки версий из `0x08`) стоит
оставить хотя бы в свёрнутом виде — пригодится при отладке.

## 7. Минимальный набор, если резать до предела

Один экран и четыре команды:

```
подключиться -> 0x04 (время) -> 0x15 (границы и уставка)
слушать 0x00 -> заряд, температура, состояние, ошибка
0x16 -> уставка
0x02 -> старт/стоп
```

Этого достаточно, чтобы варить кофе. `0x17`/`0x18` добавляют тонкую настройку,
`0x23`/`0x24` — отложенный запуск, `0x06`/`0x19` — счётчики.
